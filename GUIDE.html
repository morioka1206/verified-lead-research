01

AIに、調べ方のルールを渡す。

Skillは「仕事の手順書」と、その手順を助けるプログラムをまとめたものです。

独立したWebアプリではありません。いつものClaude CodeやCodexの会話から使い、検索・公式サイトの確認・証拠の保存を同じ流れで進めます。商材が未定でも「山梨県の製造業を一覧にしたい」のように依頼できます。

探す条件を、一緒に整理。

商材・地域・会いたい会社・除外条件を質問します。食品、機械、ホテルなど、調べる内容に合わせて質問が変わります。

国内・海外の会社を調査。

輸入・卸・販売・製造・ホテル・代理店などが対象です。地域は県単位でも国単位でも設定できます。

サイトを実際に取得。

普通の取得を先に試し、必要な場合はPlaywrightで表示します。会社案内・商品・所在地など、1社最大5取得先で確認します。

不確かさも、隠さない。

根拠不足・対象外・取得不能を分けて記録。公開メールや明確な問い合わせ先は、見つかった場合だけ残します。

証拠をあとから確認。

短い日本語の会社概要と、元サイトの原文・証拠URL・確認日時を保存します。必要なら人の品質チェック表も作れます。

大きな調査は、小分けに。

大量調査は既定で50候補ずつ記録。同じ会社の重複を整理し、保存済みの続きから再開できます。

例：アメリカの抹茶卸、タイの工業ネジ販売会社、イタリアの高級ホテル、日本の製造業や建設業。相手が新しい取引に応じるか、購入予算があるかまでは、サイトの情報だけでは分かりません。
02

大切なのは、AIの名前より調べ方。

通常のAIでも丁寧な調査はできます。このSkillは、確認の手順を毎回そろえます。

単発のリスト生成とこのSkillの確認手順の比較
確認点会社名を挙げてもらうだけの場合このSkillのルール
会社とURL記憶や推測、古い情報が混ざる可能性検索で候補を見つけ、公式サイトを取得
条件との一致説明がもっともらしくても、根拠が不明なことがあるAIの対象判定と、3種類のサイト上の根拠が必要

STEP 04リストに保存必要なら人も確認

合格には、3種類の根拠が必要です。

事業・商材との関係扱う・使う・製造する・販売するなど。会社一覧なら、対象の事業を営んでいること。
会社の役割卸、販売代理店、製造会社、施工会社など、今回探す相手であること。
対象地域との関係拠点・販売・配送など、相談時に決めた地域条件を満たすこと。

プログラムは、引用した証拠文が取得した本文にあるかも確認します。AIが accepted と判断し、3種類の根拠がそろい、除外条件も確認できた会社だけが合格です。

自動で合格へ格上げしません。 AIが競合・対象外として review や rejected にした会社は、証拠がそろっても合格にしません。除外条件が未確認・該当・判断不能の会社も合格にしません。証拠不足なら判定を下げます。

これは誤りを減らし、確かめ直しやすくする仕組みです。サイトの記載自体が古い場合や、会社の役割を読み違える場合もあり、正確性を保証するものではありません。

03

いつものClaude Codeに、追加する。

ここからは、Claude Codeを既に使っている方のための導入手順です。

必要なものは、MacまたはWindows、インターネット、使える状態のClaude Code、Python 3です。必要な部品はプロジェクト専用の環境へ入れるので、普段のPython環境と分けて使えます。

最初の1回だけ ブラウザ用の部品をダウンロードします。通信速度によって時間がかかるため、完了表示が出るまで待ってください。このSkill自体は外部AIのAPIキーを要求しません。Claude CodeやCodex側の利用契約・利用上限は別です。

まず、フォルダを入手する。

配布用ZIPをダウンロードして展開します。MacではZIPをダブルクリック、WindowsではZIPを右クリックして「すべて展開」を選びます。中に GUIDE.html、skills、.claude-plugin があるフォルダを使います。ZIP版のフォルダ名は verified-lead-research-main です。

既にGitで取得したフォルダがあれば、それを使って構いません。配布元と内容を確認してから実行してください。

ZIPの中身は随時更新されます。 このリンクはGitHubの本番ブランチ（main）をZIPにするものです。修正が本番へ反映されると、同じリンクから新しい内容を取得できます。すでに保存・展開したフォルダは自動更新されません。ZIP版は再ダウンロード、Git版は変更を確認して最新版を取得してください。
会社調査の実行はパソコン向けです。 Mac／Windows上のPythonと調査用ブラウザを使います。スマホ・iPadは、この説明書や完成したスプレッドシートを見る用途で使えます。端末上でSkillを直接動かす構成ではありません。Codexを使う方はCodex専用の導入手順へ進んでください。
お使いのパソコンを選ぶ

Macの手順

  1. ターミナルで、展開したフォルダへ移動する

    Spotlight（⌘＋スペース）で「ターミナル」を検索して開きます。cd と半角スペースを入力し、Finderの展開済みフォルダをターミナルへドラッグして、Enterを押します。

    cd は「このフォルダで作業する」という指定です。以下は、そのフォルダへ移動した状態で実行します。

  2. Pythonが使えるか確認する

    ターミナルに入力 → Enter
    python3 --version

    Python 3.x.x のようなバージョンが出れば次へ。

    見つからなければ、Python公式サイトからPython 3を導入し、ターミナルを開き直してください。

  3. 必要な部品を準備する

    ターミナルに入力 → Enter
    python3 skills/verifying-sales-leads/scripts/bootstrap.py

    専用のPython環境、必要なライブラリ、Chromiumを準備します。英語の経過表示は正常です。

    最後に ready: …/.venv/bin/python と出て、入力待ちに戻れば成功です。

  4. ブラウザが裏側で動くか確認する

    ターミナルに入力 → Enter
    .venv/bin/python skills/verifying-sales-leads/scripts/check_browser.py --output runs/browser-diagnostic.json

    "status": "ok" が出れば成功です。画面にブラウザが開かなくても正常です。

  5. このフォルダのPluginを読み込んで起動する

    ターミナルに入力 → Enter
    claude --plugin-dir .

    Claude Codeの入力画面が開いたら、下の「Skillを呼び出す」へ進みます。

Windowsの手順

  1. 展開したフォルダでPowerShellを開く

    エクスプローラーで展開済みフォルダの中を開きます。上のアドレス欄（フォルダの場所が出る欄）へ powershell と入力し、Enterを押します。そのフォルダで作業する青色または黒色の画面が開きます。

  2. Pythonが使えるか確認する

    PowerShellに入力 → Enter
    py -3 --version

    Python 3.x.x と出れば次へ。

    見つからなければPython公式サイトからPython 3を導入し、PowerShellを開き直します。py が使えず python --version がPython 3を示す環境では、次の最初の行を python -m venv .venv に置き換えます。

  3. 必要な部品を準備する

    下の4行を上から1行ずつ実行してください。エラーが出たら次へ進まず、「困ったとき」を確認します。

    PowerShellに1行ずつ入力
    py -3 -m venv .venv
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\.playwright-browsers"
.\.venv\Scripts\python.exe -m pip install --requirement .\skills\verifying-sales-leads\requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium

    専用環境を作り、ライブラリとChromiumを入れます。Activate.ps1 の実行や、PowerShellの実行ポリシー変更は不要です。

    各行でエラーがなく、ブラウザのダウンロードが終わって入力待ちに戻れば次へ。

  4. ブラウザが裏側で動くか確認する

    PowerShellに入力 → Enter
    .\.venv\Scripts\python.exe skills\verifying-sales-leads\scripts\check_browser.py --output runs\browser-diagnostic.json

    "status": "ok" が出れば成功です。画面にブラウザが開かなくても正常です。

  5. このフォルダのPluginを読み込んで起動する

    PowerShellに入力 → Enter
    claude --plugin-dir .

    Claude Codeの入力画面が開いたら、下の「Skillを呼び出す」へ進みます。

Skillを呼び出す — ここからはClaude Codeに入力

ターミナルの通常の入力欄ではなく、起動したClaude Codeの会話欄に次を入力します。

Claude Codeに入力 → Enter
/verified-lead-research:verifying-sales-leads

調査したい条件を聞かれれば、読み込みは成功です。

この方法は、その起動中だけPluginを読み込みます。 永続的なマーケットプレイスインストールではありません。次回も同じフォルダで claude --plugin-dir . を実行してください。末尾の . は「いま開いているフォルダ」の意味です。フォルダを削除しないでください。
Macのダブルクリック導入と、個人用Skill登録について

Macには INSTALL.command も同梱しています。ダブルクリックすると部品の準備に続いて、Codex用の管理コピーとClaude Code用のリンクを個人用Skillフォルダへ登録します。登録後はアプリを開き直してください。

Claude Codeの個人用Skillは /verifying-sales-leads で呼び出します。Plugin方式の長いコマンドとは別です。二重導入しないよう、どちらか一方の方式を選んでください。

macOSの警告で実行できない場合は、保護機能を無効化せず、配布元とファイルの内容を確認してください。不明な警告を無理に解除する必要はありません。上記の手動準備とPlugin方式も選べます。

Codexへの登録は、次の独立したCodex導入ガイドで案内しています。

参考：Claude Code公式のPlugin説明 · Windowsの補足手順

WindowsでPluginとブラウザを試験した記録はありますが、最新の全変更をWindows実機で再確認したことを意味しません。各PCでブラウザ診断を実行してください。

03b

Codexで使うための導入手順。

Codexが使えるPCへ、個人用Skillとして追加する方法です。Claude Codeは不要です。

ここでは配布フォルダに入っている登録スクリプトを使います。Pluginストアへの登録や、Claude Code用の claude --plugin-dir . は実行しません。Codexへの登録と、Python・Chromiumの準備は別の作業です。

  1. 配布フォルダを入手し、そのフォルダで作業画面を開く

    最新版ZIPを展開します。Macはターミナルで cd と半角スペースのあとへフォルダをドラッグしてEnter。Windowsは展開済みフォルダをエクスプローラーで開き、アドレス欄へ powershell と入力してEnterを押します。

    作業場所は GUIDE.html と skills があるフォルダです。今後も使うので削除しないでください。

  2. 必要な部品を準備し、ブラウザを確認する

    下でOSを選び、上から1行ずつ実行します。すでに同じフォルダで準備済みなら、診断だけで構いません。Python 3が見つからなければ、Python公式サイトから導入してください。

    準備の最後に ready:、診断で "status": "ok" が出れば次へ。

    続けてCodex用のSkillを登録する

    同じターミナルに入力
    .venv/bin/python skills/verifying-sales-leads/scripts/install_skill.py --codex-only

    copied: と登録先が表示されれば、コピーは完了です。

    各行でエラーがなく、診断で "status": "ok" が出れば次へ。

    py がなく python --version でPython 3が使える環境では、先頭を python --version、次の行を python -m venv .venv に置き換えます。

  3. Codexを開き直し、元の作業フォルダを開く

    登録後はCodexを終了して開き直し、展開した verified-lead-research-main を作業フォルダに選んで新しい会話を作ります。画面上の項目名はアプリの版によって異なります。Skillのコピー先ではなく、Python環境を準備した元のフォルダで調査してください。

    Codexの会話欄に入力（ターミナルではありません）

    Skill一覧が表示される環境では verifying-sales-leads を選んでも構いません。Claude Code用のスラッシュコマンドをCodexへ入力する必要はありません。

Codexに登録したのに見つからない

登録時の copied: の行と、使用中のCodexの版を確認してください。Codexへ「この配布フォルダのSkillを使いたい。現在の環境が読み込むSkillの場所と、登録先の違いを確認して」と依頼します。最新の配置先が必要な場合も、既存のSkillや設定を勝手に削除・上書きしないでください。

Skillのコピーには元フォルダを示す .managed-source が含まれます。SKILL.md だけを抜き出さず、scripts や references も含むフォルダ一式を維持します。

次回の起動・Codex用Skillの更新

次回はCodexで同じ作業フォルダを開き、Skillを指定するだけです。claude --plugin-dir . は不要です。ブラウザ実行の許可が求められた場合は操作内容を確認し、フルアクセスへ一律に切り替える必要はありません。

更新は配布元を最新版にし、必要な部品を準備してから、この節の install_skill.py --codex-only をもう一度実行します。管理対象でない既存フォルダは上書きせず停止します。別フォルダにZIPを展開した場合、古い登録先と競合することがあるので、エラーを無視して削除しないでください。調査記録の runs/ も残します。

この導入方法はローカルPC向けです。スマホ・iPad上や、ブラウザのChatGPTにZIPを添付するだけで同じ処理が動くわけではありません。リモート接続機能を使う場合も、調査処理は接続先のPCで動きます。

04

最初は、日本語で依頼するだけ。

条件を相談して、最後に確認してから検索へ進みます。

Skillを呼び出したあとの会話欄に入力
日本産の業務用抹茶をアメリカへ売りたいです。
輸入会社と卸会社の候補を、公式サイトの証拠付きで探してください。

すぐに検索せず、商材・対象地域・会社の役割・除外条件・必要件数を聞き取ります。質問は固定ではありません。食品なら用途や競合の扱い、地域の会社一覧なら「本社だけか、工場や支店も含むか」など、結果を変える点を確認します。

  • 工業用ネジをタイへ販売するため、卸・販売会社を探したい

05

大きな調査も、50候補ずつ。

件数を増やしても、合格の基準は同じです。

モード合格の目標確認候補の上限
標準調査5〜50社最大100候補
大量調査51〜1,000社最大5,000候補

大量調査は既定で50候補ずつ進め、判定と証拠を research.sqlite3 へ保存します。例として500社の依頼なら、候補上限を2,500社程度に設定し、目標または候補上限に達した時点で終了します。

0150候補を確認一社ずつ同じ基準
02台帳へ保存判定と原文証拠
03重複を整理会社の単位で確認
04次のまとまりへ目標か上限で終了

途中でやめたら、どうする？

元のプロジェクトフォルダを開き直し、保存された runs/ の調査フォルダ名をAIに伝えて「この調査を続きから再開して」と依頼します。台帳と途中結果は移動・削除しないでください。閉じている間も自動で調査が進むわけではありません。

1,000社は目標であって、取得保証ではありません。 公式サイトや必要な証拠が見つからなければ、確認できた件数と不足理由を報告します。1,000社を超える調査を別実行へ分ける場合も、既存リストとの重複確認と条件の再確認が必要です。
06

使う表は、シンプルに。

営業用の一覧と、品質確認のための記録を分けます。

結果はプロジェクト内の runs/調査フォルダ/ に保存します。まずは leads.xlsx を開けば大丈夫です。

leads.xlsx

営業に使う全件リスト。

会社名、公式URL、会社種別、短い日本語の概要、見つかった公開メールなど。判定欄・確認メモ・大きなタイトル行は入れません。見出しの固定と絞り込みができます。

leads.csv

別のツールへ渡すデータ。

会社情報を日本語の項目で保存します。Excel以外のシステムへ取り込む場合に使えます。メールや問い合わせ先が空欄でも、推測で埋めません。

audit.json

「なぜ選んだか」の記録。

合格以外も含む全候補、判定理由、元サイトの原文、証拠URL、確認日時を保存します。普段は開かず、疑問がある時にAIへ渡して確認できます。

quality-review.xlsx / Google Sheets

希望した場合だけ、確認用の表。

営業リストとは別に、正しい・間違いとメモを入力できます。10社だけ、全件、今回はしない、から選べます。Google Sheetsへの直接作成は別途接続・認証が必要です。

research.sqlite3

大量調査の途中経過。

調査済み・未調査の候補、重複整理、進捗を覚える台帳です。通常は開く必要はありませんが、再開するために残しておきます。

summary.json

いま、どこまで進んだか。

確認済み候補数、合格数、目標までの残り、次の作業を確認するための記録です。

品質チェックは任意です。 10社を確認する場合、先頭10社ではなく、判断が難しい会社と種類の違う代表例を混ぜます。9社以上が正しければ簡易チェックは合格、8社以下なら20社または全件へ広げます。これは全件の精度を証明する統計調査ではありません。迷う判定は勝手に「正しい」にせず、理由を確認します。

Googleスプレッドシートを作っただけでは、他の人へ自動公開されません。共有相手と範囲は持ち主が決めます。

07

できることと、しないこと。

連絡する前の、会社探しと確認のための道具です。

  • 会社名・URL・メールを想像で埋めません。
  • 問い合わせフォームや営業メールを送信しません。営業文もこの調査の成果物には含めません。
  • Bot対策やCAPTCHAを突破しません。読めないサイトは取得不能・確認待ちとして扱います。
  • 問い合わせフォームは、通常の調査で明確に見つかった場合だけ記録し、クリックして深追いしません。
  • 非公開ページやログインが必要な情報を集めません。robots.txt、アクセス間隔、安全なURLの制約を守ります。
  • 会社サイトの表示だけで、法人登記・許認可・認証の現在の有効性を公的に証明しません。
  • マーケットプレイスの出店者一覧や、フランチャイズ各店舗の収集は対象外です。
取得不能 ≠ 会社が存在しない。 PCのブラウザ起動不良、サイトの制限、情報不足は分けて扱います。正確さを犠牲にして目標件数を埋めません。
08

更新と、困ったときの案内。

分からない時は、エラーの文章を残して相談してください。

次回は、どこから起動すればよい？

元のフォルダでターミナル／PowerShellを開き、claude --plugin-dir . を実行します。初回の準備を毎回やり直す必要はありません。Claude Codeが開いたら /verified-lead-research:verifying-sales-leads を呼び出します。

個人用Skill登録を選んだ場合は /verifying-sales-leads です。Plugin方式と混同しないでください。

Skillが見つからない・質問が始まらない

現在のフォルダに .claude-plugin/plugin.json と skills があるか確認します。1段外のフォルダや、ZIPの中のままでは正しく読み込めません。Claude Codeを終了して、正しいフォルダで claude --plugin-dir . から開き直してください。

claude が見つからない場合は、普段Claude Codeを起動しているターミナル環境で試します。組織の設定でPluginが禁止されている場合は、管理者へ確認してください。

ブラウザ診断が environment_error になった

runs/browser-diagnostic.json とエラー全文をAIへ渡してください。個別の会社を調べる前に、PC側でブラウザが動くかを直します。安全設定の解除や --no-sandbox による回避は勧めません。

Windowsでは、上の準備手順でブラウザ保存先を指定してからChromiumを入れたか確認します。Macではbootstrapを実行したフォルダと、診断を実行したフォルダが同じか確認します。

準備中に赤いエラーが出た・画面が止まったように見える

ダウンロード中は時間がかかる場合があります。エラーが出たら、その文章をコピーするか画面を保存してください。「成功」とみなして次へ進まず、OS名と実行した段階を添えて相談します。

別のPython版や会社PCの制約が関係する場合もあります。分からないまま管理者権限で実行したり、PowerShellの実行ポリシーを下げたりする必要はありません。

新しい版へ更新するには？

ZIP版：新しいZIPを別のフォルダに展開し、そのフォルダで初回準備とブラウザ診断を実行します。新しいフォルダからPluginを起動します。過去の runs/ は消さず、再開したい場合は元の場所をAIへ伝えます。.venv を別の場所へコピーして使うのは避けてください。

Git版：自分の変更がある場合は先に確認・保存し、通常の方法で最新版を取得します。依存ライブラリが変わっていれば、Macはbootstrap、WindowsはライブラリとChromiumの準備を再実行して診断します。

個人用Skill：Macの登録スクリプトを再実行します。管理対象でない既存Skillを勝手に上書きしないため、競合時は止まります。Claude Codeのリンクを使う場合は、参照元フォルダを残してください。

API契約や追加のサービス契約は必要？

このSkill自体は外部AI APIキーや検索API契約を要求しません。使うClaude CodeやCodexの利用条件・費用・上限は、それぞれの契約に従います。ブラウザだけで使うChatGPTやClaudeの通常の会話に、このフォルダを渡すだけで同じ実行環境が付くわけではありません。

Googleスプレッドシートは自動で作られる？

この配布物だけでGoogleアカウントへ接続する機能は入りません。使っているAI環境にGoogle Sheetsを作成できる接続があれば、その認証後に作成できます。接続できなければ、Excelの確認表を使うか、Excel／CSVをGoogle Sheetsへ取り込んでください。

問い合わせフォームやメールが空欄でもよい？

大丈夫です。連絡先は補助情報です。見つからなければ空欄にし、会社の合否とは分けます。問い合わせフォームの探索だけに時間をかけることはしません。

証拠を読める言語に訳してもらえる？

会社概要や根拠の説明を日本語で依頼できます。あとから確かめられるよう、audit.json には原文とURLも残します。翻訳だけで重要な除外条件を判断しきれない場合は、確認待ちとして扱います。

このガイドやSkillを、ほかの人へ渡したい

このページのURLとGitHubの配布元を渡せます。導入する人が自分のPCで準備します。調査データや連絡先を共有する必要はありません。

公開ガイドは GUIDE.html と同じ内容です。公開処理はこのHTMLだけを専用フォルダへコピーし、runs/、台帳、ログ、認証情報は含めません。
