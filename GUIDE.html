VERIFIED LEAD RESEARCH

公式サイトの証拠付きで、営業候補を探すSkill

売りたい商材、対象国、会いたい企業を伝えると、候補企業の公式サイトを確認し、なぜ候補に入れたのかまで残します。会社名やURLをAIの想像だけで作りません。

Codex対応Claude Code対応AI API契約不要営業送信なし
インストールする普通のAIとの違い
ひとことで言うと「会社をたくさん挙げるAI」ではなく、「会社を一社ずつ確かめるAI」です。

このSkillでできること

抹茶や和牛だけでなく、売りたいものと営業目的を変えて使えます。

聞

条件を選択式で整理

固定アンケートではなく、商材と回答に合わせて必要な質問だけを出します。

探

海外の候補企業を発見

輸入、卸、販売店、ホテル、工場、代理店、提携先などを探せます。

確

公式サイトを確認

トップ、会社概要、商品、卸売、問い合わせなどを一社最大5ページ確認します。

残

証拠を一緒に保存

会社名とURLだけでなく、公式サイトの原文、掲載ページ、確認日時を残します。

連

公開連絡先を収集

公開メールだけを取得。問い合わせフォームは普通に見つかった時だけ保存します。

分

不確かな会社を分離

証拠不足、対象外、取得不能を分け、無理に「合格」へ入れません。

商材例食品、飲料、機械、素材、化粧品、日用品、法人向けサービス。B2Bの相手を公式サイトで確認できる商材に向いています。

普通のAIリストより、なぜ信頼しやすいの？

違いはAIモデルの名前ではなく、調べ方にあります。ChatGPTやClaudeへ一度に会社名を尋ねるだけでは、記憶、推測、古い情報が混ざることがあります。

確認点普通のAIリストこのSkill
会社名・URLAIの記憶や推測が混ざることがあるWebで候補を見つけ、公式サイトを取得
営業先との適合「それらしい会社」を文章から判断3種類の公式サイト証拠を必須にする
メール命名規則から推測する場合があるページに公開されたメールだけ
根拠説明文だけで、あとから確認しにくい原文・URL・確認日時を保存
分からない時空欄を埋めようとすることがある確認待ち・対象外・取得不能に分ける

嘘を入りにくくする5つの関門

01候補を検索会社を記憶だけで挙げない
02公式サイト取得URLが実際に開けるか確認
033証拠を探す商材・役割・市場活動
04原文を再確認証拠文がページ内にあるか検査
05人が最終確認正しい・間違いを記録

企業が合格するには、次の3つがすべて必要です。

商材との関係
扱う・使う・販売する
＋
会社の役割
輸入・卸・購入など
＋
対象市場の活動
販売・配送・顧客・拠点

SETUP

はじめてのインストール

Macはダブルクリック、WindowsはPowerShellから準備できます。最初だけ必要なブラウザ部品をダウンロードするため、通信環境により3〜10分ほどかかります。

先に必要なものMacまたはWindows、インターネット、CodexまたはClaude Code、Python 3。CodexとClaude Codeは、使いたい方だけで大丈夫です。

受け取ったフォルダを開く

`verified-lead-research` というフォルダです。ZIPで受け取った場合は、まずダブルクリックして展開します。

`INSTALL.command` をダブルクリック

黒い画面が開きます。英語が表示されても、閉じずにそのまま待ってください。

「完了しました」を待つ

必要な部品とブラウザを準備し、CodexとClaude Codeから使える場所へSkillを置きます。

アプリを開き直す

最後にEnterキーを押して黒い画面を閉じ、CodexまたはClaude Codeを再起動します。

新しい会話で依頼する

下の依頼文をコピーして試します。Skillが質問を始めれば成功です。

Macに止められたら`INSTALL.command` を右クリック →「開く」→ もう一度「開く」。知らない配布元のファイルを開く警告が出た時だけ、この操作をします。
WindowsでClaude Codeを使いたい

ZIPを展開するかGitHubから取得し、`verified-lead-research` フォルダでPowerShellを開きます。次を上から順に実行します。

py -3 -m venv .venv
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\.playwright-browsers"
.\.venv\Scripts\python.exe -m pip install --requirement .\skills\verifying-sales-leads\requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
claude --plugin-dir .

Claude Codeで /verified-lead-research:verifying-sales-leads を選びます。さらに詳しい説明は Windows版セットアップ手順 にあります。

Windowsでブラウザが動くか確認したい
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\.playwright-browsers"
.\.venv\Scripts\python.exe -m unittest tests\test_playwright_dynamic.py -v
最後に OK と表示されれば合格です。ブラウザは裏側で動くため、画面が開かないのが正常です。

Codexを完全に終了して開き直し、新しいタスクを作ります。特別なコマンドは不要です。

Claude Codeを終了して開き直します。Skillを直接呼ぶ場合は /verifying-sales-leads と入力できます。

Python 3が見つからないと言われた
Python公式サイトからPython 3をインストールし、その後もう一度 `INSTALL.command` を開いてください。
黒い画面を使わず、自分でインストールしたい
cd /受け取った場所/verified-lead-research
python3 skills/verifying-sales-leads/scripts/bootstrap.py
.venv/bin/python skills/verifying-sales-leads/scripts/install_skill.py
管理者としてClaude Code Pluginを直接テストしたい
claude --plugin-dir /受け取った場所/verified-lead-research
この配布フォルダにはClaude Code用とCodex用のPlugin設定が両方入っています。

最初の使い方

新しい会話へ、売りたいものと国を普通の日本語で書きます。

日本産の業務用抹茶をアメリカへ売りたいです。
輸入会社と卸会社の候補を、公式サイトの証拠付きで探してください。

すぐには検索せず、Skillが選択式で質問します。質問は固定ではありません。食品なら業務用・小売用、機械なら代理店・導入企業など、今回の結果を変える内容だけを聞きます。

検索が始まるタイミング最後に条件が一枚で表示されます。内容を確認して「この条件で調査を開始」を選ぶと、会社探しが始まります。

ほかの依頼例

  • 和牛をヨーロッパへ販売するため、食肉輸入会社を探す
  • 包装機械を東南アジアへ販売するため、販売代理店を探す
  • 日本の化粧品原料を韓国へ販売するため、メーカーと卸会社を探す
  • 法人向けサービスの現地パートナー候補を探す

最後に受け取るもの

leads.csv

営業担当が見る日本語の表。

  • 会社名と公式URL
  • 公開メール
  • 短い会社概要
  • 証拠URL
  • 人の確認欄

audit.json

あとから判定を確かめる記録。

  • 全候補と判定
  • 公式サイトの原文
  • 証拠ページ
  • 確認日時
  • 不確かな点

最初の抹茶・アメリカ実験では、37候補を確認し、3証拠がそろった30社を出力しました。利用者が30社すべての公式URLを確認し、30社すべてを正しいと判定しました。

37公式サイト確認
303証拠で合格
30 / 30人の確認で正しい

このSkillがしないこと

  • 会社名、URL、メールアドレスを想像して埋める
  • 問い合わせフォームや営業メールを送信する
  • CAPTCHAやBot対策を回避する
  • 問い合わせフォームだけを探すため、無制限にクリックする
  • 公式サイトだけを根拠に、法人登記済みだと断定する
30社に届かないことがあります証拠が足りない時は、数を埋めるために合格条件をゆるめません。不足数と理由を報告します。

困ったとき

インストール後もSkillが始まりません
CodexまたはClaude Codeを完全に終了し、開き直してから新しい会話を作ってください。古い会話では新しいSkillが読み込まれないことがあります。
アップデートはどうしますか？
新しい配布フォルダへ入れ替え、もう一度 `INSTALL.command` を開きます。このインストーラーが以前に置いたファイルだけを更新します。
ChatGPTやClaudeのAPI契約は必要ですか？
このSkillをCodexまたはClaude Codeの会話内で使う段階では、別のAI API契約は不要です。将来、独立したWebアプリとして自動運転する場合は別途実行基盤が必要です。
問い合わせフォームが空欄でも大丈夫？
大丈夫です。フォーム探索は補助機能です。フォームだと明確に確認できた時だけ保存し、分からない場合は空欄にします。会社の合否は、商材・会社の役割・対象市場の活動という3種類の証拠で決まります。
