# 公開マニュアル統合仕様

2026-11-06、会話で承認済み。既存の1ページガイドを更新し、公開する限定的な変更。

## 目的

Claude Codeを既に使っている人が、このページだけでSkillの意味・導入・利用・更新を理解できるようにする。国内・海外の調査に使えることと、通常のAIへの単発依頼との違いを説明する。

## 合意した内容

- 既存 `GUIDE.html` の説明、使い方、大量調査、成果物、FAQを、新しいデザインに統合する。
- 承認された見本の白・アイボリー・深緑、控えめな文字サイズ、編集的な余白を採用する。スマートフォンでも読める構成にする。
- Claude Codeの導入を中心に、Mac／Windowsの手順を説明する。Codexの案内も残す。
- 各操作について入力場所、実行内容、成功の見分け方を示す。初回準備と次回起動を区別する。
- `GUIDE.html` を唯一の更新元とし、同じ内容をGitHub Pagesに公開する。
- 公開するのはマニュアルだけ。調査データ、連絡先、ログ、台帳を公開しない。
- Skill本体の調査処理や合格条件は変更しない。

## 検討した方法

GitHub Pagesはリポジトリの更新と一緒に保守できる。Sitesは独立したホスティングとして便利だが、今回の既存HTMLには更新場所が増える。ユーザーはGitHub Pagesを選択した。

## 実装上の判断

既存と同じ静的HTML・CSS・JavaScriptで構築し、新しいアプリ基盤や外部フォントを追加しない。GitHub Actionsの公開処理は `GUIDE.html` を専用成果物の `index.html` にコピーし、そのディレクトリだけを送る。公開URLの有効性を確認するまで、公開完了とは報告しない。

## 説明の正確さ

ローカルPlugin読み込みと個人用Skill登録を区別する。Google Sheets接続は別途必要。外部AI APIキーをSkillが要求しないことと、Claude Code等の利用契約・制限を区別する。件数や100%の正確性を保証しない。人による品質チェックは任意とする。取得不能と会社が存在しないことを混同しない。

## 完了条件

既存の主要な説明を引き継ぎ、ページ内リンク、コピー、OS切り替え、キーボード操作、狭い画面を確認する。公開成果物にマニュアル以外が入らないことをテストする。READMEとSTATUSに案内・現在地を記録する。既存の無関係な変更をコミットに含めない。
