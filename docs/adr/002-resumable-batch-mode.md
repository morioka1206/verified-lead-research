# ADR 002: 再開可能な大量調査モード

## 決定

Skill版に、50候補ずつ処理して途中保存できる大量調査モードを追加する。標準モードは合格50社・候補100社までとし、大量モードは合格1,000社・候補5,000社までを設定可能にする。

## 理由

500社規模を一つの会話と一つの巨大ファイルだけで処理すると、途中停止、重複調査、進捗の見失いが起きやすい。外部サーバーやAI APIを導入する前に、CodexとClaude CodeのローカルSkillだけで、安全に分割・再開できる形を作る。

## 方法

- `runs/<日時>/research.sqlite3` に候補、バッチ、完了記録を保存する
- 公式ドメイン単位の一意制約で、全バッチをまたいだ重複を防ぐ
- 開いているバッチがある間は次のバッチを作らない
- バッチ内のクロールと評価が全件一致した場合だけ完了として保存する
- バッチ完了ごとに日本語CSV、監査JSON、進捗JSONを再出力する
- 既存CSVの人手判定欄は再出力時も保持する

## 変えないこと

- 1社最大5ページ
- 商材、会社の役割、対象市場の3証拠
- 公開メールだけを取得する
- 問い合わせフォームは任意
- CAPTCHAやアクセス制限を回避しない
- 候補上限で不足しても合格条件を下げない

## 限界

Web検索と証拠判断はCodexまたはClaude Codeの会話内で行うため、完全な無人運転ではない。1,000社を超える依頼、大量並列実行、複数利用者の同時操作は将来のアプリ版で扱う。
