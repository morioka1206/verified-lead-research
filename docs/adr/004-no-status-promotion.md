# ADR 004: 最終確認プログラムはAI判定を格上げしない

## 決定

最終 `accepted` は、AI評価の `recommendation` が `accepted` であり、商材・会社の役割・対象市場という3種類の証拠が取得本文内で確認できた場合だけ認める。

最終確認プログラムは、証拠不足やサイト取得不能を理由に判定を下げられる。一方、AIが競合、対象外業態、その他の文脈判断から `review` または `rejected` にした企業を `accepted` へ格上げしてはならない。

## 理由

3種類の証拠は「その会社が商材、市場、役割に関する文章を掲載している」ことを示すが、「今回の営業対象として適切である」ことを単独では保証しない。たとえば、抹茶を卸売する競合企業は3証拠を満たしても、買い手候補ではない。

## 判定表

| AI recommendation | 3証拠 | 最終判定 |
|---|---:|---|
| `accepted` | あり | `accepted` |
| `accepted` | 不足 | `review` |
| `review` | あり／不足 | `review` |
| `rejected` | あり／不足 | `rejected` |
| 任意 | サイト取得不能 | `blocked` |

## テスト

`review` と `rejected` のそれぞれについて、3証拠がすべて実在するケースを作り、`accepted` に変わらないことを確認する。
