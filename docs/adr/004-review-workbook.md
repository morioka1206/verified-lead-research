# ADR 004: 営業リストと品質チェック表を分ける

## 決定

`leads.xlsx` を `leads.csv` と同時に作る。Excelは営業に使う主画面とし、CSVは他システムへ渡すために残す。`leads.xlsx` には人の判定欄や確認メモを入れない。

営業用Excelには次を含める。

- 会社名、公式URL、会社概要、公開連絡先
- 商材との関係、対象地域、確認日時
- 見出し固定、フィルター、クリックできるURL

リスト完成後にだけ、品質チェックを希望するか尋ねる。選択肢は「10社だけ（推奨）」「全件」「今回はしない」とする。品質チェックを希望した場合だけ、Googleスプレッドシートまたは別ファイル `quality-review.xlsx` を作る。確認表には、3種類の証拠と証拠URL、`正しい`／`間違い`の入力欄、確認メモ、確認ガイドを含める。

10社は先頭から取らず、不確実性が残る難しい会社と、会社種別の異なる代表例を混ぜて決定的に選ぶ。10社中9社以上が正しければ簡易チェック合格、8社以下なら20社または全件へ広げる。結果は全件の厳密な精度ではなく、抜き取り確認率として扱う。

複数人で確認する場合は、Google Drive接続が利用できる実行環境に限り、確認表をネイティブGoogleスプレッドシートにする。判定列はGoogle Sheetsのドロップダウンとして設定する。共有権限は営業リスト作成とは別の判断なので、自動では変更しない。

## 理由

営業担当者には判定欄や長い証拠URLが邪魔になる一方、品質確認者にはそれらが必要になる。1つの表へ両方を詰め込まず、利用目的ごとに分けると分かりやすい。10社の抜き取り確認なら、全件を読まなくても重大な分類ミスを早期に見つけやすい。

## 互換性

配布先のmacOSとWindowsで同じ結果を作れるよう、Skill内の生成処理には固定バージョンの `openpyxl` を使う。CodexまたはClaude Codeの外部AI API契約は不要である。
