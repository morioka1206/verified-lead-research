# 用語集

- **候補会社**: Web検索で見つけた、まだ合格か分からない会社。
- **公式サイト**: その会社自身が運営していると判断できるWebサイト。
- **証拠**: 公式サイトに実際に書かれている短い文章と、そのページURL。
- **accepted（合格）**: AIが営業対象として合格と判断し、商材・会社の役割・対象地域の3種類の証拠も確認できた会社。
- **review（確認待ち）**: 証拠が一部足りない、または意味があいまいな会社。
- **rejected（不合格）**: 取得できた情報から対象外と判断した会社。
- **blocked（取得不可）**: robots.txt、Bot対策、通信エラーなどで十分に確認できない会社。
- **監査JSON**: AIの判断が本当かを調べ直すため、原文証拠を保存したファイル。
- **human_verdict**: 人が最後に付ける「正しい」「間違い」の答え。
- **精度**: 合格会社のうち、人が確認して正しかった会社の割合。
